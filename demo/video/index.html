Video demo

A recorded lecture played from MP4 files. Switch between one video and two, and turn the intro and outro on to see how they chain.

Demo options

What to try

  • Layouts. Open ⚙ Settings → Layout: side by side, picture in picture, speaker only or slides only.
  • Sync. Seek anywhere: the timecodes burned into both videos stay together.
  • Captions. They switch on by themselves because the video has caption tracks. Change the language in Settings.
  • Descriptions. With a screen reader, turn on ⚙ Settings → Descriptions (screen reader) to hear what is on screen. Alternative audio, such as an audio-described track, shows up under Audio when the media carries it.
  • Chapters. Three of them, marked on the progress bar. Hover the bar to see where each one falls, or jump to one from ⚙ Settings → Chapters.
  • Transcript. The page icon in the bar opens it below the player: the current phrase follows along, and any phrase jumps there.
  • Resume. Leave halfway and reload: playback continues where you were, and says so.
  • Media keys and lock screen. Play/pause keys and headphone buttons work, and on a phone the lock screen shows the title, the chapter and the poster. Next and previous jump between chapters.
  • Floating window. The button next to the gear moves the video to the browser's floating window. With Presentation only it is the slides that float.
  • Intro and outro. Tick the box above. The intro has a Skip intro button; the outro can't be skipped or fast-forwarded.
  • Nothing loads early. Until you press play there is no <video> on the page and no video has been downloaded.
Keyboard shortcuts

Tab moves through the controls · Space or K plays and pauses · ← → seek 5 s · J L seek 10 s · ↑ ↓ volume · M mutes · F full screen · 0–9 jump to that percentage.

Inside the settings menu, the arrow keys move between items, and Esc goes back one panel before closing.

What it takes

import { create } from '@nanoplayer/core';
import { attachControls } from '@nanoplayer/ui';
import '@nanoplayer/plugin-captions';   // they register themselves
import '@nanoplayer/plugin-chapters';
import '@nanoplayer/plugin-pip';
import '@nanoplayer/plugin-audio-tracks';
import '@nanoplayer/plugin-media-session';
import '@nanoplayer/plugin-quality';
import '@nanoplayer/plugin-resume';
import '@nanoplayer/plugin-transcript';

const player = create('#player', { manifest: '/api/video/123' });
attachControls(player);
