Live demo

Two live streams — camera and slides — kept in sync by the time of day they were broadcast.

A public test channel stands in for a real lecture. Both streams come from the same 24/7 channel kindly provided by ireplay.tv, so the two halves should always show the same frame: that is what being in sync looks like. If the channel is down, the demo is too.

What to try

  • Two synced live streams. Kept together by their broadcast time (EXT-X-PROGRAM-DATE-TIME), not by when each one started loading. Both halves show the same frame.
  • Rewind and return. Drag the bar back — the channel keeps about 25 minutes — then press Go to live to jump back to the latest moment.

Also handled

This channel is always on air, so it can't show these, but the player covers them:

  • Before it starts. A clear notice that the broadcast hasn't started yet, retrying on its own until it does.
  • When one drops out. If the slides stop, the camera keeps playing and the notice appears only where the slides were.

What it takes

create('#player', {
  manifest: {
    id: 'closing-ceremony',
    live: true,
    streams: [
      { id: 'camera', role: 'presenter', audio: true,
        sources: [{ src: 'camera.m3u8', type: 'application/vnd.apple.mpegurl' }] },
      { id: 'slides', role: 'presentation', audio: false,
        sources: [{ src: 'slides.m3u8', type: 'application/vnd.apple.mpegurl' }] },
    ],
  },
});
