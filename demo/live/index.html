Live demo

Two live streams — camera and slides — kept in sync by the time of day they were broadcast.

This demo doesn't work yet. There is no live stream connected to this page, so pressing play will only show the notice that the broadcast hasn't started. The player itself supports live streams; what's missing is a stream to point it at.

What it will show

  • Two synced live streams. Kept together by their broadcast time (EXT-X-PROGRAM-DATE-TIME), not by when each one started loading.
  • Rewind and return. Go back within the live window, then use the LIVE button to jump back to the latest moment.
  • Before it starts. A clear notice that the broadcast hasn't started yet, retrying on its own until it does.
  • When one drops out. If the slides stop, the camera keeps playing and the notice appears only where the slides were.

What it takes

create('#player', {
  manifest: {
    id: 'closing-ceremony',
    live: true,
    streams: [
      { id: 'camera', role: 'presenter', audio: true,
        sources: [{ src: 'camera.m3u8', type: 'application/vnd.apple.mpegurl' }] },
      { id: 'slides', role: 'presentation', audio: false,
        sources: [{ src: 'slides.m3u8', type: 'application/vnd.apple.mpegurl' }] },
    ],
  },
});
