NanoPlayer

El reproductor tal cual lo vería quien lo integre: dual-stream sincronizado, subtítulos en dos idiomas y menú de ajustes. Sin controles de laboratorio.

Cómo se prueba con el teclado

Tab recorre los controles · Espacio o K reproduce · ← → saltan 5 s · J L saltan 10 s · ↑ ↓ volumen · M silencia · F pantalla completa · 0–9 saltan a ese porcentaje.

Dentro del menú de ajustes recorren las flechas, no Tab, y Esc retrocede un panel antes de cerrar. 

import { create } from '@nanoplayer/core';
import { attachControls } from '@nanoplayer/ui';
import '@nanoplayer/plugin-captions';   // se auto-registra

const player = create('#player', { manifest: '/api/video/123' });
attachControls(player);
