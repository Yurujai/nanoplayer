Playlist demo

Three lectures in a row. Previous and next sit in the bar, the whole list in the settings menu, and when one lecture ends the next one starts.

In this course

    What to try

    • Next and previous. In the bar, on the right with the other buttons. Previous is not shown on the first lecture, nor next on the last.
    • The list. ⚙ Settings → Playlist jumps to any lecture; so does the list beside the player.
    • On to the next. Jump near the end of a lecture (9 goes to 90 %): when it finishes, the next one starts on its own.
    • Each lecture is its own. The first has one video, the second speaker and slides with chapters and captions, the third an intro and an outro. The bar adapts to each.
    • Keyboard. Press next with Enter: focus stays on the button in the new lecture's bar, so you can keep going.

    What it takes

    <script src="nanoplayer.min.js"></script>
<script>
  const list = NanoPlayer.createPlaylist('#player', {
    items: ['/api/video/1', '/api/video/2', { manifest: '/api/video/3', title: 'Entropy' }],
    // start: 0, autoAdvance: true, loop: false, and any create() option
  });
  list.next(); list.previous(); list.go(2);
</script>

    Each lecture gets a fresh player in the same container: a player belongs to one manifest. With npm, @nanoplayer/playlist does the same given a create function, as this page does.
